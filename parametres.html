Libellés

Change le texte d’une tâche, d’une date importante, d’une info utile ou d’un titre. Seul le texte affiché change : les dossiers et leurs données ne bougent pas. Un même texte est changé partout où il apparaît.

Documents POI

Le bouton « Documents POI » d’un projet ouvre le dossier du projet, où tu vois docs GEDAFFAIRE : POI › type de dossier › « adresse - COMMUNE (N° POI) ». Le dossier du projet est retrouvé grâce à son N° POI entre parenthèses.

Disponible seulement dans le logiciel installé sur le PC.

Modèles Excel vierges. À la création du dossier d’un projet, une copie de chacun est déposée dans son sous-dossier « Fiches préremplies », avec les N° POI dans le nom. Types de dossier cachés

Un type caché n’a plus d’onglet ni de bouton « + Nouveau projet ». Ses projets restent dans « Dossiers en cours ».

Corbeille

Un projet supprimé reste ici 30 jours, puis disparaît pour de bon.

Jours non travaillés

Les dates calculées des ComL ne tombent jamais un week-end ni un jour férié français (calculés tout seuls chaque année). Ajoute ici d’autres jours à éviter, par exemple un pont.

Code admin

Le code protège la partie admin des Paramètres. C’est un simple verrou : il n’empêche pas quelqu’un qui a ta session Windows de lire tes fichiers.
